# Camo Swatch

Drop a landscape photo and get a seamless, tileable camouflage pattern. Color extraction, pattern weaving, premade suggestions, stealth scoring, and export all run in the browser. No photo is uploaded.

Open the site, or open `index.html` from this folder.

- Military: organic, digital, contour, cellular, tiger stripe, brushstroke, fleck
- Hunting: broadleaf, branch, marsh, open grass, bark, and pine forest, each with type and density controls
- Samples include a pine forest, plus mossy forest, desert, urban, and snow
- Use Optimize to search combinations and keep the highest stealth score
- Each palette color shows the closest Krylon spray, including a color picked from the photo. The camouflage cans are Black, Brown, Khaki, Olive, Sand, and Woodland Light Green. The chip is a screen match; the can will not be exact.
- Export: SVG, per-color stencil SVGs, 2048 PNG tile, field card, hex / CSS / JSON
